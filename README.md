# personal-website

My personal website, hosted on GitHub Pages with a custom domain.

## Structure

```
index.html   — Homepage (hero, about, projects, contact)
styles.css   — Minimal stylesheet
CNAME        — Custom domain for GitHub Pages
```

## Custom domain

Replace the placeholder in `CNAME` with your actual domain, then configure
your DNS provider to point to GitHub Pages (see the
[GitHub Pages docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site)).
